# Summarise Therapy Line Duration & Time to Next Line (TTNL)

Summarise Therapy Line Duration & Time to Next Line (TTNL)

## Usage

``` r
summariseTherapyLineDuration(cohort)
```

## Arguments

- cohort:

  A LOT cohort table generated by
  [`generateTherapyLineCohortSet()`](https://iomedhealth.github.io/DrugUtilisation/reference/generateTherapyLineCohortSet.md).

## Value

A summary dataframe containing patient counts, TTNL (days & months),
exposure duration, and treatment-free gap metrics.

## Examples

``` r
if (FALSE) { # \dontrun{
library(DrugUtilisation)
cdm <- mockDrugUtilisation()
# ...
summariseTherapyLineDuration(cdm$lot_cohorts)
} # }
```
